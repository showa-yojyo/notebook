特徴
================================================================================

下に挙げるもの以外は割愛。

中括弧展開演算子
--------------------------------------------------------------------------------

例をいくつか挙げる：

* :code:`{1..10}`, :code:`{10..1}` などで数列を展開する。空白文字区切り（以下同
  様）。
* :code:`{a..z}`, :code:`{z..a}`, :code:`{e..m}`, etc. で文字列を展開する。
* :code:`"Number #"{1..4}`, etc. で分配法則が働いて展開する。
* :code:`{1..3}{x..z}" +"` で直積を展開する。だからこの例では末端に要らない
  ``+`` が残る。
* :code:`{{a..c},{1..3}}` とすると、まず ``{a..c}`` を展開してその次に
  ``{1..3}`` を展開する。中央にある ``,`` に注意すること。

.. seealso::

   `Bash 中括弧展開ノート <https://gist.github.com/showa-yojyo/500a833243aaec0976c2ddb13fdb2660>`__

配列の添字を展開する記法
--------------------------------------------------------------------------------

配列変数 ``array`` に対して、``${!array[@]}`` は ``array`` に割り当てられた配列
のインデックス（キー）の一覧に展開される。

.. seealso::

   `Bash 変数展開ノート <https://gist.github.com/showa-yojyo/7a7005f5d909964a140468a927a57169>`__

正規表現演算子 ``=~``
--------------------------------------------------------------------------------

* 二重角括弧の内部で用いる。
* :code:`if [[ "This is a fine mess." =~ T.........fin*es* ]];`
* こういう状況における正規表現に対して引用符で囲むのは望ましくないとある。正規表
  現を展開するのに失敗するかもしれないそうだ。

.. seealso::

   `Bash 二重角括弧ノート <https://gist.github.com/showa-yojyo/6c223d863a717999d8edd43a4fa113b5>`__

オプション :command:`set -o pipefail`
--------------------------------------------------------------------------------

オプション ``pipefail`` が on である場合、パイプラインの戻り値が非ゼロステータス
で終了した最後の（右端の）命令の値になる。パイプライン内のコマンド全てが正常に終
了した場合は、戻り値はゼロとなる。

シェルスクリプトの先頭で on にする記述があるのをよく見かける：

.. sourcecode:: bash

   #!/bin/bash

   set -o errexit
   set -o nounset
   set -o pipefail

演算子 ``+=``
--------------------------------------------------------------------------------

演算子 ``+=`` が使いやすくなった。代入演算子 ``=`` しか使えなかった状況でも演算
子 ``+=`` を使えるようになる。とりわけ ``PATH`` の追加に使える。
