特徴
================================================================================

ANSI-C quoting
--------------------------------------------------------------------------------

記法 ``$'...'``、バックスラッシュでエスケープされた文字をそのように翻訳させる。
これはコマンドラインからスペース文字を入力するのにも有用だ。

.. sourcecode:: console

   bash$ echo '\n'
   \n
   bash$ echo $'\n'


   bash$

この機能は ANSI-C quoting と呼ばれている。改行やタブなどの空白文字を quote する
ほかに、端末で色文字を出力するのにも使える。

.. seealso::

   `Bash quoting ノート <https://gist.github.com/showa-yojyo/88f7f1b954b6ecb7013aeb347f22c68a>`__

間接引数参照
--------------------------------------------------------------------------------

``${!ptr}`` のような記法を間接変数参照という。ある変数の値を別の変数の名前として
使用することが可能になる。例：

.. sourcecode:: bash

   suffix=VERSION
   name="BASH_${suffix}"

   echo ${!name}  # e.g. 5.3.9(1)-release

配列変数
--------------------------------------------------------------------------------

配列変数が使用可能だ。負の添字を許すなどの特徴がある。
