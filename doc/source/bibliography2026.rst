江戸の幽明
================================================================================

:著者: 荒俣宏
:出版社: 朝日新聞出版
:発行年: 2014 年
:ISBN: 978-4-02-273588-1
:関連 URL: <https://publications.asahi.com/product/16457.html>

詳しくノートを取りたい一冊。都内散歩候補地選定の参考にもなる。

朱引きの内外という考えが主題の部から学ぶことが多い。取材の準備が執筆作品の質に決
定的に影響することを教わった。

荒俣先生作品は語彙が独特なので飽きないが、辞書をめくり過ぎると疲れる。

名作と歩く東京山の手・下町第一集
================================================================================

:著者: 青木登
:出版社: けやき出版
:発行年: 2003 年
:ISBN: 978-4-87751-197-5
:関連 URL: 不明または調査中

文学作品の舞台や文人墨客にゆかりのある地、史跡名勝、名建築を巡る散策シリーズの第
一巻。文学作品の引用と著者自らが撮影した写真をふんだんに散りばめた、手に持ちやす
い一冊。都内散歩に訪れたい場所を探すのに向いている。

本書およびその類書は『江戸名所図会』に言及することが普通であることも理解した。

便宜のため、以下に <https://ci.nii.ac.jp/ncid/BA63556935> からパクった目次を引用
しておく。第二集から第七集までのコメントについても利用する。

#. 無縁坂界隈を歩く—湯島天神から麟祥院・上野公園へ
#. 皇居内堀を歩く—靖国神社から千鳥ケ淵緑道・桜田門へ
#. 青山霊園界隈を歩く—高橋是清翁記念公園から乃木公園・青山病院跡へ
#. 世田谷粕谷界隈を歩く—蘆花恒春園から世田谷文学館へ
