概要
======================================================================

Crop And Lock 機能はデスクトップにあるウィンドウのうち、その矩形部分を新たなウィ
ンドウとして生成するものだ。例えば、ブラウザーウィンドウ内の YouTube のビデオ再
生部分をくり抜いて PC 画面の隅の方に配置し、それを見ながらテキスト作業をするなど
ということが可能になる。

使い方
======================================================================

まず、後述の方法を用いて Crop And Lock 機能を有効にしておく。

#. 対象のウィンドウをアクティブにする。
#. くり抜きたい部分をマウスを使って矩形で指定する。
#. 新しいウィンドウができる。

くり抜きモードは二つある。一つは Thumbnail モードであり、これは単に原ウィンドウ
の矩形部分を眺めることに機能を絞ったものだ。これは安定して動作する。

もう一つは Reparent モードであり、これを用いてくり抜くと原ウィンドウが一時的に消
え去る。くり抜きウィンドウ経由で GUI 操作が可能であるということに公式文書では謳
われているが、試験的であるとも断っている。

.. admonition:: 利用者ノート

   使用状況にも依るだろうが、現時点では Thumbnail モードの使い勝手が優る。

設定
======================================================================

:guilabel:`Enable Crop And Lock` を On にして当機能を有効にする。

Activation
----------------------------------------------------------------------

:guilabel:`Thumbnail shortcut`
   Thumbnail モードくり抜きの発動キーバインドを割り当てる。

   既定値は :kbd:`Win` + :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`T` だ。
:guilabel:`Reparent shortcut`
   Reparent モードくり抜きの発動キーバインドを割り当てる。

   既定値は :kbd:`Win` + :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`R` だ。
