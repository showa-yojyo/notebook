======================================================================
Light Switch 利用ノート
======================================================================

.. |keybind| replace:: :kbd:`Win` + :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`D`

Light Switch は PowerToys の部分機能であり、Windows のライトモードとダークモード
を容易に切り替えることをできるようにするものだ。Windows の設定画面
``ms-settings:colors`` をいちいち開かずともだ。

.. admonition:: 利用者ノート

   私はライトモード固定でありたいので Light Switch を進んで利用することはないだ
   ろうが、撮影用に切り替える機会があるかもしれないので、この機能の使い勝手を試
   すことはしておく。

.. attention::

   :doc:`./index` 冒頭の前提条件に留意すること。

.. contents:: 見出し一覧
   :local:

使い方
======================================================================

手動で切り替える場合は |keybind| を押すたびにライトモードとダークモードが切り替
わる。

:ref:`設定画面<anchor-light-switch-schedule>` を見ればわかるように、自動で切り替
える選択肢もある。

設定
======================================================================

Light Switch 設定画面の最初にある :guilabel:`Enable Light Switch` を On にするな
どの方法で当機能を有効にする。

Shortcuts
----------------------------------------------------------------------

:guilabel:`Theme toggle shortcut`
   ライトモードとダークモードを切り替えるキーバインドを割り当てる。既定では
   |keybind| だ。

.. _anchor-light-switch-schedule:

Schedule
----------------------------------------------------------------------

:guilabel:`Mode`
   ダークモードを On にする時間を次の三つから決定する：

   :guilabel:`Off`
      切り替えを使用者による完全手動とする。ただし、他の二つの方式を選んだとして
      もキーバインドによる切り替えは有効だ。
   :guilabel:`Fixed hours`
      時間帯を固定し、その時刻で自動で切り替えるようにする。

      :guilabel:`Turn on dark mode`
         何時何分からであるかを指定する。
      :guilabel:`Turn off dark mode`
         何時何分までであるかを指定する。
   :guilabel:`Sunset to sunrise`
      日の入りから日の出までの時間帯とし、自動で切り替えるようにする。時間帯は

      :guilabel:`Location`
         この二つの時刻を自動計算するために、地球上のだいたいの位置を与える。

         .. caution::

            位置情報へのアクセスを許可する必要がある。
      :guilabel:`Offset (in minutes)`
         自動計算結果から分単位で時刻を調整することが可能。

Behavior
----------------------------------------------------------------------

:guilabel:`Apply dark mode to`
   ダークモードに切り替えたい対象を On/Off する：

   * :guilabel:`System`: OS 自体。
   * :guilabel:`Apps`: ダークモードを実装しているプログラムすべて。
