概要
================================================================================

YouTube や Twitter にアップロードされている音声ファイルや映像ファイルを PC にダ
ウンロードする道具として、以前は youtube-dl を利用していた。しかし、本稿で述べる
yt-dlp_ のほうが更新活動が活発そうであり、こちらに乗り換えることにした。

本稿では yt-dlp_ を Linux (WSL Ubuntu) から実行することを仮定している。こちらの
ほうがスクリプトを書きやすいし、後処理の柱である FFmpeg も Ubuntu にインストール
してあるのをそのまま利用できるからだ。

インストール・更新・アンインストール
================================================================================

YouTube の性質上、開発中最新版 |yt-dlp| を使うのが最善習慣とされている。したがっ
て、一般の :ref:`python-pkg-install-anchor` の方法を少し変形して適用する。

|yt-dlp| を（仮想環境に）明示的にインストールする場合にはこのようにする：

.. sourcecode:: bash
   :caption: 望ましいインストール・更新命令例

   pip install -U --pre "yt-dlp[default]"

他の仮想環境切り替え方式のパッケージ管理プログラムを使っているならば、上の命令行
オプションに対応するオプションと `yt-dlp[default]` 指定を使え。

|uv| を使っている場合は |yt-dlp| を実行するたびに最新版を |uv| に取得させる命令
行になる：

.. sourcecode:: bash
   :caption: |uv| 使用時の |yt-dlp| 実行例

   uvx --pre --from "yt-dlp[default]" yt-dlp ...

また、Homebrew でも |yt-dlp| を取り扱える。常に最新版ではないだろうが、YouTube
以外の用途には使えると考えられる。

構成・カスタマイズ
================================================================================

|yt-dlp| の既定動作を変更するには、次のテキストファイルに |yt-dlp| の命令行オプ
ションを羅列する方法がある：

* :file:`${XDG_CONFIG_HOME}/yt-dlp/config`

.. seealso::

   環境変数 :envvar:`XDG_CONFIG_HOME` については :doc:`/xdg` に記す。

構成ファイルでは環境変数を記述することが許されている。例えば ``$HOME`` とか
``${HOME}`` とかのように、自然に記述できる。

使用方法・コツ
================================================================================

別名を付けておく
--------------------------------------------------------------------------------

専用の仮想環境に |yt-dlp| をインストールすることにしたので、それを呼び出しやすい
ように別名を与えておくと打鍵量が少なく済む。Bash の場合は次のような行をシェル起
動ファイル :file:`.bashrc` に追加する：

.. sourcecode:: bash
   :caption: Bash での別名付与例

   alias yt-dlp='mamba run -n yt-dlp yt-dlp'

ラッパーを用意する
--------------------------------------------------------------------------------

用例に応じたシェル関数なりシェルスクリプトなりを用意しておき、すぐに実行可能な準
備を整えるのがいい。例えば、YouTube や Twitter に存在する音声映像 URL から MP3
ファイルを保存することが多い場合は、対話シェルからこんな関数を呼び出せるようにし
ておくのだ：

.. sourcecode:: bash
   :caption: |yt-dlp| を用いる関数例
   :force:

   function download_audio
   {
       local -r video_url="${1:?Usage: $FUNCNAME VIDEO_URL}"
       local -r options=(
           -q
           --no-playlist
           -t mp3
           -o "%(id)s-%(title)s.%(ext)s")

       yt-dlp ${options[@]} "$video_url"
   }
